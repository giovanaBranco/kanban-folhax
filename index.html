🔐 Autenticação Azure DevOps

Para acessar os dados do Kanban, informe sua Personal Access Token (PAT) do Azure DevOps. O token ficará salvo apenas no seu navegador.

Como gerar sua PAT:
1. Acesse Azure DevOps → User Settings → Personal Access Tokens
2. Clique em "+ New Token"
3. Dê um nome (ex: "Kanban Folha X"), defina expiração
4. Em Scopes, selecione Read em "Work Items"
5. Copie o token gerado e cole acima
